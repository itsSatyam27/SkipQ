Scope: current student, faculty and seller app flows, local Firestore emulator, browser UI fixtures, source review, deployed Firestore rule comparison, and notification service health. Live user/order data was not changed. Browser fixtures mock AppContext callbacks; they do not establish real-device or production end-to-end success.

## Explicitly unavailable in this release

UPI checkout and wallet/top-ups are intentionally unavailable and labelled accordingly. Legacy UPI verification/cancellation paths remain in the code and emulator coverage. These should not be counted as working new-payment methods.

## Needs real-device end-to-end verification

No Android device was attached to ADB during this audit. Actual Google sign-in, Android location permission/GPS enforcement, FCM foreground/background/terminated delivery and sound, camera/gallery photo selection, offline/reconnect behaviour, and OTA download/restart remain unverified. Existing production APK signing and native OTA configuration were verified during build 8 release, but that does not establish an actual OTA installation on a phone.

The findings above describe the original audit snapshot. See the follow-up below for the implemented fixes.

## Fix verification — 19 October 2026

- Five-dish checkout now stays within the Firestore expression budget while preserving menu/price integrity, including legacy source snapshots.
- No-show status, strike count and ban policy update atomically. Repeated submissions cannot double-count, and existing longer bans cannot be shortened.
- Preparation options render in normal layout; zero-minute preparation remains zero.
- Completed-order reviews now persist. Buyers can select stars for each ordered dish; the matching dish/canteen card and preview display average/count. Unrated dishes say “Not rated yet”. Editing a review replaces its existing public entry. Public entries contain only shop ID, dish stars and update time; order/customer links remain private.
- Rush mode prioritizes ready pickups and shows preparation grouped by dish.
- Seller update settings are under Account → Profile → App updates. Student/faculty settings remain under Profile → Help → App updates.
- Verification: 60 unit tests, 31 Firestore emulator tests, and browser checks for dish card/preview ratings, visible stars, review payload and seller update settings passed. Native release configuration passed.
- Real-device limitations listed above still apply. Publication status is recorded in OTA_UPDATES.md; local checks alone do not prove a phone has installed an update.
